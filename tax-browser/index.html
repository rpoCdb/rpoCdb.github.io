rpoCdb v3.1 — 178,199 bacterial reference genomes (GTDB r232), reduced to 113,471 unique taxonomic paths after in-silico PCR deduplication and lowest-common-ancestor collapse of byte-identical rpoC amplicons. "Representative" links to the example genome accession on NCBI for that taxonomic path. Species names ending in a placeholder code (e.g. sp900xxxxxx) denote GTDB genomospecies without a validly published binomial. Archaea are not included here — a dedicated archaeal database is in preparation. Data and pipeline: rpoCdb/rpoCdatabase.
